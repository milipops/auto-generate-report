# Инструкции по деплою на GitHub

Так как прямой доступ к GitHub из окружения ограничен, выполните следующие шаги
на вашем локальном компьютере:

## Шаг 1: Инициализация Git репозитория

```bash
cd путь/к/ForWorkTest
git init
git add .
git commit -m "Производственные отчёты: разбор переписки мастеров и сохранение в SQLite"
```

## Шаг 2: Подключение удаленного репозитория

```bash
git remote add origin https://github.com/zamaletdinovr575-web/ForWorkTest.git
```

## Шаг 3: Отправка кода в репозиторий

```bash
git branch -M main
git push -u origin main
```

## Шаг 4: Настройка проекта

1. Скопируйте `.env.example` в `.env`
2. Заполните необходимые значения:
   - `AI_API_KEY` — ключ ИИ (обязателен для полноценного отчёта с Excel;
     без него отчёт собирается упрощённо)
   - `WEB_HOST` / `WEB_PORT` — адрес сайта, по умолчанию `127.0.0.1:8080`
   - `OCR_LANGS`, `TESSERACT_CMD` — если фото читаются локально, а Tesseract
     не в PATH

Секретов для запуска больше нет: сайт локальный и работает без внешних
сервисов. Обязательный ключ только один — ключ ИИ.

## Шаг 5: Установка и запуск

```bash
pip install -r requirements.txt
python main.py
```

Сервер поднимется на адресе из `.env` и откроет страницу в браузере.

Проверить разбор отчётов без запуска сайта:

```bash
python tests/test_parser.py
```

   в `services/yandex_source.py`.
2. **Расширение парсера** под новые форматы сообщений по мере появления.
3. **Экспорт накопленных записей** в новых форматах — Excel, файл для 1С и

Все изменения коммитьте с понятными сообщениями:
```bash
git add .
git commit -m "Описание изменений"
git push
```
